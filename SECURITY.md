# Security and responsible use

## Reporting

If you find a vulnerability or a data-handling issue, please open a private
report to the maintainers rather than a public issue.

## Handling recovered data

Outputs of this tool can contain highly sensitive personal data recovered
from a browser profile: prompts, email and calendar content, uploaded-file
URLs, and account identifiers. Treat all outputs as sensitive evidence:

- redact account identifiers and host paths before sharing;
- never commit real acquisitions or outputs to a repository;
- store and transmit outputs only through channels appropriate for the
  sensitivity of the underlying evidence.
